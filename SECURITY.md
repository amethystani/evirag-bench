# Security policy

Report vulnerabilities privately through [GitHub's private vulnerability reporting](https://github.com/amethystani/evirag-bench/security/advisories/new). Please do not open a public issue.

You can expect an acknowledgement within a week. The supported version is the latest release.

The tool talks to a local Ollama server and, optionally, the OpenAlex API. It does not send corpus or query data anywhere else. Keep any `OPENALEX_API_KEY` out of committed files.
